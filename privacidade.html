Privacidade e dados

Privacidade

Esta é uma versão demonstrativa para portfólio, separada do site utilizado pelo cliente. Não é possível solicitar orçamentos por esta página.

Formulário demonstrativo

Use apenas dados fictícios. O formulário valida os campos no navegador e abre uma página de confirmação. O código não envia nem armazena os valores preenchidos.

Recursos externos

As fontes são carregadas pelo Google Fonts. Essa conexão e a hospedagem da página podem gerar registros técnicos de acesso nos respectivos serviços. Esta versão não inclui scripts de publicidade, analytics ou reCAPTCHA.

Links externos

Os contatos e links comerciais foram substituídos por exemplos. Ao abrir um serviço externo, como Instagram, WhatsApp ou iFood, aplicam-se as políticas desse serviço.
